
# Image Enhancement Studio

## Overview
Image Enhancement Studio is a Python application that improves
images using image-processing techniques and a simple web interface.

## Features
- Upload images in PNG, JPG, JPEG, WEBP, and BMP formats
- Adjust brightness and contrast
- Improve image sharpness
- Adjust color saturation
- Apply grayscale and sepia filters
- Apply blur, smooth, detail, and edge-enhancement filters
- Rotate and resize images
- Preview original and enhanced images
- Download enhanced images in PNG or JPEG format

## Technologies Used
- Python
- Streamlit
- Pillow

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal.
